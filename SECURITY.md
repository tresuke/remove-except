# Security Policy

## Supported Versions

Security fixes are provided for the latest released version of `remove-except`.

## Reporting a Vulnerability

Please report suspected vulnerabilities privately through GitHub's **Report a
vulnerability** feature for this repository. Do not open a public issue for an
unfixed vulnerability. Include the affected version, impact, and steps to
reproduce in your private report.

If the reporting feature is unavailable, do not publish vulnerability details
in issues or discussions. A private reporting channel must be enabled before
reports can be accepted.

Please avoid including sensitive data that is not necessary to reproduce the
issue. The maintainer will acknowledge reports and coordinate disclosure after
the issue has been assessed and a fix or mitigation is available.
